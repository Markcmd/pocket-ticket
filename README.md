# Pocket Ticket

服务员自己用的点单记录本。在桌边记下客人点的菜，回到 POS 机前对着输入。
不连 POS、不算钱，只是记录。

## 怎么用

1. 首页是 1–17 号桌，点一桌进去
2. 先选人数，再选套餐：Special A / Special B / Special Premium（一桌只能选一种，之后点顶部的套餐标签可以改）
   - 客人还没决定套餐、想先点水或饮料：按 **先点酒水饮料**，之后再按 **+ 选套餐**
3. **点单**：按分类点菜，点一下加一份；底部"本次 N 份"可以展开调数量、写备注
4. 按 **下单** → 自动跳到 **已点**
5. **已点** 页面：
   - 最上面是"新增 · 待输入 POS"，输进 POS 后按 **已输入 POS ✓**
   - 下面是这桌全部已点的合计，还没输入 POS 的会标出 "+N 新"
6. 客人走了按 **清桌**

首页桌号上会显示套餐，还有几次下单没输入 POS。

右上角 **中 / 한 / EN** 按钮切换菜名的主要语言（另外两种小字显示）。

## 套餐内容

- **Special A**：1–22 号
- **Special B**：1–36 号
- **Special Premium**：Special B 全部 + Premium A–D
- 酒水饮料所有套餐都能点

菜单数据在 [`menu.js`](menu.js)，改菜单只要改这个文件。

## 数据

所有记录只存在这台设备的浏览器里（localStorage），不会上传到任何地方。
换手机或清除浏览器数据，记录就没了。

## 本地运行

纯 HTML/CSS/JS，不需要安装任何东西：

```bash
python3 -m http.server 8765
```

然后打开 http://localhost:8765
